WEBSITE RESTORAN

Nama Project:
Website Restoran

Deskripsi:
Website restoran yang dibuat menggunakan HTML dan CSS.
Website memiliki beberapa halaman seperti Beranda, Menu, Event,
Tentang, Kontak, dan Reservasi.

Teknologi:
- HTML5
- CSS3

Fitur:
- Halaman beranda
- Daftar menu makanan dan minuman
- Halaman event
- Halaman tentang restoran
- Halaman kontak
- Halaman reservasi
- Gambar dan video pendukung
- Navigasi antar halaman
- Animasi dan tampilan responsif

Struktur Folder:
- index.html       : Halaman utama
- menu.html        : Halaman menu
- event.html       : Halaman event
- tentang.html     : Halaman tentang restoran
- kontak.html      : Halaman kontak
- reservasi.html   : Halaman reservasi
- style.css        : File CSS utama
- images/          : Folder gambar website
- video/           : Folder video website

Cara Menjalankan:
1. Download atau clone repository.
2. Buka file index.html menggunakan browser.
3. Pastikan folder images dan video tetap berada di dalam folder project.

Dibuat untuk tugas praktik HTML dan CSS.
