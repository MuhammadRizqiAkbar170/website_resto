# Website Restoran - Front End

Website restoran yang dibuat sebagai tugas Front End Development dengan menggunakan HTML dan CSS serta bantuan Artificial Intelligence (AI) dalam proses pengembangan.

## 📌 Deskripsi

Website ini dibuat untuk menerapkan dasar-dasar Front End Development, terutama dalam penggunaan HTML dan CSS untuk membuat tampilan website yang modern, menarik, dan responsif.

Website memiliki beberapa halaman yang saling terhubung dan menggunakan gambar serta video sebagai media pendukung.

## ✨ Fitur

- Halaman Beranda
- Halaman Menu
- Halaman Event
- Halaman Tentang
- Halaman Kontak
- Halaman Reservasi
- Navigasi antar halaman
- Penggunaan gambar dan video
- Animasi dan efek visual
- Tampilan responsif

## 🛠️ Teknologi

- HTML5
- CSS3
- Artificial Intelligence (AI) sebagai alat bantu pengembangan
